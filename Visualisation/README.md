
# Visualizations

This folder contains the visualizations generated during the Exploratory Data Analysis of the Digital Fatigue & Academic Burnout dataset.

The visualizations help present patterns, distributions, comparisons, and relationships identified throughout the analysis.

The visualizations are organized according to the major analytical sections of the project:

- Respondent Profile
- Digital Usage Analysis
- Digital Fatigue Analysis
- Academic Burnout & Well-being
- Relationship & Correlation Analysis

The visualizations were created primarily using Python's Matplotlib and Seaborn libraries.
